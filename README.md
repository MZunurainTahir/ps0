# ps0 — Git and JUnit Lab (6.005 / CS166)

## Description
This repository contains the solution and unit tests for **Problem Set 0 (ps0)** focusing on Git version control fundamentals and JUnit test-driven development in Java.

### Key Features
* **Rules Implementation (`RulesOf6005.java`):** Logic implementation for checking code usage and collaboration guidelines in assignment submissions (`mayUseCodeInAssignment`).
* **Unit Testing (`RulesOf6005Test.java`):** Comprehensive JUnit 4 test cases validating edge cases, public citations, course work restrictions, and implementation requirements.
* **Git Workflow Practice:** Complete version control workflow including branching, merging, staging, and commit history management.

### Tech Stack
* **Language:** Java
* **Testing Framework:** JUnit 4
* **IDE:** Eclipse / IntelliJ IDEA
* **Version Control:** Git
